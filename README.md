# 🚀 My Portfolio Website

A responsive personal portfolio website built using HTML, CSS, JavaScript and Django to showcase my skills, projects, and achievements.

## 🌐 Live Demo
👉 https://hema-portfolio-4yw8.onrender.com

## ✨ Features
- Fully responsive design for all devices
- Modern and clean UI
- Mobile-friendly hamburger navigation
- Sections included: About, Skills, Projects, Certificates, Coding Profiles, Contact
- Smooth animations and interactive UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Django
